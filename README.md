# video-editing-

R0BATO Media editing workspace.

- `briefs/`: insert and edit briefs. Every brief ends with an exact Avoid list and a checkable Done-means list. Start from `briefs/_TEMPLATE.md`.
- `explainers/`: Remotion source for motion explainers. Rendered video, footage and client photos stay out of git.
- `reels/`: build and QA scripts for footage reels, one folder per job. Each folder's README is its brief, with Avoid and Done-means lists.
- `skills/r0bato-video/SKILL.md`: the latest r0bato-video skill, with Rob's lessons from these jobs. A copy for version history; the live skill is saved in claude.ai.
